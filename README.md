# Maaş Sayacı

Maaş Sayacı, aylık maaşı 30 güne bölerek maaşın 7/24 nasıl aktığını canlı gösteren eğlenceli Android uygulamasıdır.

## V1 Özellikleri
- Aylık maaş girişi
- 30 gün üzerinden hesaplama
- Bu ay kazanılan para
- Bugün kazanılan para
- Günlük / saatlik / dakikalık / saniyelik kazanç
- WC, yemek, toplantı ve yatış modları

## APK Alma
GitHub Actions sekmesinden `Build Android APK` workflow'u çalıştır.
Bittiğinde Artifacts bölümünden `maas-sayaci-apk` indir.
